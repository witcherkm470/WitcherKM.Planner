# AGENTS.md

## Карта репозитория

- `src/` — backend solution: `Domain`, `Application.Common`, `Application`, `Infrastructure`, `Api`.
- `scripts/` — React-клиент.
- `shared/` — общая конфигурация.
- `docs/` — SDD-документация: продукт, архитектура, дизайн, зависимости, спецификации, решения и правила реализации.

## Работа со спецификациями

Требования к фичам находятся в `docs/specs/`. Читайте только документацию, относящуюся к текущей задаче.

Перед реализацией агент обязан:

1. Прочитать релевантную спецификацию.
2. Прочитать релевантную архитектурную документацию.
3. Изучить существующую реализацию.
4. Реализовать только требования спецификации.
5. Не придумывать отсутствующие продуктовые требования.
6. Проверить Acceptance Criteria после реализации.

Если spec конфликтует с архитектурой, сообщите об этом до реализации. Если существующая spec изменилась, сначала используйте `git diff`, чтобы определить изменение требований; не переписывайте существующую реализацию без необходимости.

Для кода также прочитайте относящийся к задаче файл из `docs/rules/`: он задаёт строгий порядок работы, Clean Architecture/DDD-границы и требования к сохранению текущего code style.
