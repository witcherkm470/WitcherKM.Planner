# Проверка взаимодействий

Это процедура проверки; требования бери из UI spec и общего контракта диалогов.

## Асинхронные страницы

- Проследи загрузку, успешное чтение, пустой результат и отказ отдельно.
- Задержи первый ответ, переключи фильтр/карточку, верни второй ответ раньше первого. Таблица и ошибка должны принадлежать актуальному запросу.
- Проверь смену фильтра во время записи: последующее обновление использует текущий фильтр. При переходе к другой сущности старые формы и данные не предлагают действия над прежней сущностью.
- После изменения проверь повторное чтение и независимые счётчики, включая скрытый фильтром новый объект.

## Формы и клавиатура

- Пройди создание, заполненный edit, отмену и терминальное состояние для затронутого действия; обязательность полей бери из domain/application.
- Открой выбор родителя клавиатурой, выбери пункт, закрой список Escape без закрытия формы. Tab/Shift+Tab не должны теряться на удалённых DOM-элементах.
- Задержи сохранение: повторная отправка и закрытие не вызывают вторую запись.
- Верни ошибку: закрывается только верхний диалог, черновик остаётся, фокус возвращается в форму, повторная попытка использует введённые значения.
- Проверь имя каждого диалога при нескольких одновременно открытых ошибках, видимый фокус, длинные значения и доступность формы на узком экране.
