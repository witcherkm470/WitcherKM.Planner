Прочитай spec страницы, [общий контракт диалогов](../../../docs/specs/ui/dialogs.md), docs/architecture/frontend.md и docs/design/frontend.md. Составь карту: действие → форма/прямой запрос → результат → обновляемые данные. Недостающая форма — часть заявленного действия; новую бизнес-операцию не придумывай.

Повторно используй существующие компоненты и hooks согласно architecture. Для асинхронных страниц, составных селектов и вложенных диалогов применяй [проверку взаимодействий](references/interactions.md); для простой визуальной правки не загружай её целиком.

Покрой изменённое поведение через [testing](../testing/SKILL.md), затем проверь в браузере фокус, состояние ошибок и видимый результат. Укажи, какие действия проверены и был ли backend настоящим.
