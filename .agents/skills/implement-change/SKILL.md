description: Реализует согласованное изменение Planner по canonical specs и change-документу, исправляет подтверждённые расхождения кода с требованиями.
---

Прочитай AGENTS.md, docs/specs/README.md и релевантный срез specs/architecture. Используй git diff, чтобы отличить новые требования от прежних. Сохрани изменения пользователя.

Определи затронутые domain/application/UI требования и критерии приёмки. Для существенного поведения добавь регрессионную проверку и, когда возможно, продемонстрируй её падение до исправления. Следуй testing skill, не ослабляй существующие проверки.

Исправь только согласованное поведение; при неоднозначности запиши вопрос в docs/specs/questions.md. Технические решения бери из architecture, не из копий правил в skills. После тестов и сборок сверь каждое требование с наблюдаемым результатом; используй spec-management для синхронизации canonical и архива. Сообщи оставшиеся вопросы и реальные результаты проверок.
