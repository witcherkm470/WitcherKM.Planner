# Конфигурация и секреты

API получает все настройки через `IConfiguration`. Общий `shared/appsettings.json` содержит только обычные значения и подключается при запуске. Источники с рабочими секретами имеют больший приоритет. `MediatR:LicenseKey` обязателен: API завершает запуск при пустом значении, не выводя ключ в ошибку.

## Среды

| Среда | Источник ключа MediatR | Область хранения |
| --- | --- | --- |
| Локальная разработка | .NET User Secrets проекта API | Профиль разработчика, вне Git. |
| Локальный Docker | Файл Docker Compose secret | Игнорируемый каталог `secrets/` на хосте; в контейнере только `/run/secrets/`. |
| Будущий собственный сервер | Файл секрета или управляемый источник секретов | На сервере, вне образа и репозитория. |

В Docker применяется стандартный .NET `KeyPerFile` provider: имя файла `MediatR__LicenseKey` соответствует ключу `MediatR:LicenseKey`. API читает `/run/secrets` после обычных источников, чтобы секрет имел приоритет. Файл секрета монтируется только в API. Он существует на хосте и требует ограничения доступа и резервного копирования на стороне владельца сервера.

`WitcherKM.EcosystemSettings` — приватный каталог имен, назначения и примеров значимых настроек. Рабочие значения в нём не хранятся, а Planner не обращается к GitHub при запуске. `WitcherKM.Common` не участвует в чтении конфигурации: для этого достаточно стандартных провайдеров .NET.

Сейчас БД Planner — SQLite в постоянном Docker-томе, без пароля. Если появится серверная БД, её учётные данные станут отдельным секретом установки. Клиенты браузера и мобильного приложения не получают серверные секреты.
