# Initial spec: проекты

## Контекст

Эта спецификация фиксирует только уверенно восстанавливаемое существующее поведение проекта. Она не определяет новые требования.

## Требования

- Проект имеет непустое название и необязательное описание.
- Пользователь может получить список проектов.
- Пользователь может создать проект, изменить его название и описание, а также получить карточку проекта.
- Карточка проекта содержит поле документации и число фич в состоянии `Opened`.
- Пользователь может удалить проект только при отсутствии связанных фич.

## Acceptance Criteria

- Создание проекта с пустым или состоящим только из пробелов названием завершается ошибкой доменной проверки.
- Созданный проект доступен в списке и по идентификатору.
- Изменения названия и описания отражаются в возвращаемой модели проекта.
- Удаление проекта со связанной фичей не выполняется.
