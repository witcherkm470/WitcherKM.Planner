# Словарь предметной области

| Термин | Значение |
| --- | --- |
| Project / проект | Контейнер фич; название, описание, документация, состояние. |
| Feature / фича | Часть проекта с названием, описанием и состоянием; родитель задач. |
| Task / задача | Единица работы внутри одной фичи. В C# сущность называется TaskItem, чтобы не смешивать её с System.Threading.Tasks.Task. |
| Idea / идея | Независимая запись с сутью Essence и состоянием реализации. |
| Открытые фичи | Только FeatureStatus.Opened, не InProgress. |
| Открытые задачи | Только TaskStatus.Open, не InProgress. |
| Завершённая фича | FeatureStatus.Completed = 3. В старой prose-spec называлась Done; это одно и то же состояние, API не переименовывается. |
| Завершённая задача | TaskStatus.Done = 3. |

Связи: Project → Feature → Task; Idea ни к одной из них не привязана. Существование родителя проверяет application через репозиторий, ссылочную целостность сохраняет БД. Это не локальная проверка одного объекта.

Текущие корни изменения: Project, Feature, TaskItem, Idea — каждый загружается и сохраняется отдельным репозиторием. Навигационные коллекции не означают, что при любом действии загружен весь граф. Межобъектные правила описаны с указанием нужных данных. Целевой переход к одному большому агрегату этим изменением не вводится.

Undefined = 0 во всех enum — техническое значение; публичные конструкторы его не создают. Уникальность имён, лимиты длины, приоритеты, сроки и пользователи не специфицированы.
