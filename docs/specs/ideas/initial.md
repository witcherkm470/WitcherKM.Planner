# Initial spec: идеи

## Контекст

Эта спецификация фиксирует только уверенно восстанавливаемое существующее поведение проекта. Она не определяет новые требования.

## Требования

- Идея имеет суть (Essence), которая не может быть пустой и статус, который показывает, была ли реализована идея (Realzied).
- Новая идея создаётся со статусом (NotRealized).
- Идея может иметь статус отклонена (Canceled).
- Пользователь может получить список идей. Список идей показывается пользователю в виде таблицы со столбцами "Суть", статус и кнопки действий.
- Должна быть возможность редактировать и удалять идеи, запрещено редактировать и удалять Realized идеи Для таких идей скрывать эти кнопки. 
- Должна быть возможность поменять статус у идеи. Статус можно поменять с Canceled на NotRealized и с NotRealized на Realized или Canceled.
- Кнопка фильтрации с двумя состояниями. Первое состояние, которое выбрано по умолчанию, показывает все идеи, у которых статус не Canceled. Второе состояние показывает только Canceled идеи.

## Acceptance Criteria

- Создание идеи с пустой или состоящим только из пробелов сутью завершается ошибкой доменной проверки.
- Созданная идея доступна в списке.
- Изменения сути отражаются в возвращаемой модели идеи.
- Удаление идеи со статусом Realized запрещено.
