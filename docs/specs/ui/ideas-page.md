# Идеи — /ideas

Таблица: суть, статус, действия. Двухрежимный фильтр: изначально все кроме Canceled (включая Realized); второй режим только Canceled.

«Добавить идею» открывает модалку Essence; перо — заполненную форму. Череп удаляет; статусные кнопки следуют I-02. Для Realized редактирование, удаление и смена статуса скрыты. Во время запроса действия отключены.

Контракты: [идеи](../application/ideas.md), [диалоги](dialogs.md). Успех обновляет данные в текущем режиме; запись, переставшая соответствовать фильтру, исчезает из текущей таблицы. Ошибки загрузки и изменения явно показаны, черновик сохранён при ошибке.

Приёмка: пустую суть нельзя отправить; отмена без записи; Realized остаётся видна в обычном режиме; Canceled можно восстановить.
