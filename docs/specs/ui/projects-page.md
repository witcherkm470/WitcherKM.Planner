# Список проектов — /projects

Отображение: название, описание, статус и действия. По умолчанию все проекты; фильтр по Opened/Closed. Переход по строке/доступной ссылке в карточку проекта.

Действия: «Добавить проект» открывает модалку с названием и описанием; перо — такую же форму с текущими значениями; череп вызывает удаление. Ошибка удаления со связанными фичами видна пользователю, строка остаётся.

Контракты: [сценарии](../application/projects.md), [диалоги](dialogs.md). После create/update/delete список обновляется; фильтр сохраняется. Ошибка загрузки не маскируется пустым списком.

Приёмка: создание и редактирование открывают формы; отмена не пишет данные; успешное сохранение видно в таблице; фильтрация соответствует enum backend.
