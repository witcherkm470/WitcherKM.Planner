# Список фич — /features

Таблица: название, описание, проект, статус и действия. Фильтры по проекту и статусу, изначально все; строка/ссылка открывает карточку фичи.

«Добавить фичу» открывает модалку: название, описание, обязательный выбор проекта. Перо открывает редактор названия и описания. Смена статуса и удаление выполняются непосредственно; набор действий следует [Feature](../domain/feature.md). У Completed действий нет.

После успеха данные обновляются с сохранением фильтров. Ошибки загрузки проектов/фич и изменения видны. Контракты: [сценарии](../application/features.md), [диалоги](dialogs.md).

Приёмка: форма не создаёт фичу без проекта; edit заполнен; терминальные кнопки скрыты; фильтры применяются совместно.
