# Список задач — /tasks

Таблица: название, статус, действия. Изначально все задачи; фильтр по статусу. Строка/ссылка открывает /tasks/:taskId.

«Добавить задачу» открывает модальное окно: название, описание и обязательный выбор существующей фичи с указанием проекта, чтобы различать одинаковые названия. Этот выбор следует T-01, а не создаёт новый способ связи. При отсутствии фич показано объяснение, сохранение невозможно.

Перо открывает редактор с текущими названием/описанием, без перепривязки. Статусные кнопки выполняют только T-02; удаление непосредственно; у Done все изменяющие действия скрыты. Пока запрос выполняется, повторные действия отключены.

Контракты: [задачи](../application/tasks.md), [диалоги](dialogs.md). Успех обновляет список, ошибка отображается и сохраняет черновик; ошибки чтения показываются явно.

Приёмка: кнопка создания действительно открывает форму и отправляет выбранный featureId; отмена не вызывает API; ошибку можно закрыть и повторить сохранение; действие строки не вызывает навигацию вместе с нажатием пера/статуса/удаления.
