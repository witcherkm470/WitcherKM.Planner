# Общий контракт диалогов

Создание/редактирование из таблиц открывает форму в модальном окне. Исключение: карточка проекта использует уже существующий inline-редактор и диалог решения о несохранённых изменениях.

- Форма создания пустая; редактор заполнен текущими данными. Родитель, заданный карточкой, фиксирован; общая форма предлагает выбор обязательного родителя.
- Пустой обязательный текст нельзя отправить; сервер остаётся окончательным источником проверки.
- Отмена, крестик и Escape закрывают форму без записи. Пока запрос сохраняется, повторная отправка и закрытие блокируются.
- Успех закрывает форму и обновляет список/карточку/счётчик. Ошибка видна в ErrorModal, введённые данные остаются в форме для повторной попытки.
- Диалог имеет доступное название, начальный фокус, ограничение Tab/Shift+Tab своим содержимым и возврат фокуса инициатору. Вложенная ошибка возвращает фокус в исходную форму.
- Действия удаления в существующих таблицах выполняются непосредственно; обязательное подтверждение удаления не вводится. Действие смены статуса выполняет один переход непосредственно, форма ему не нужна.

Проверки: компонентные UI-тесты проверяют отправку, отмену, ошибки, доступность и блокировки; browser smoke проверяет диалог в реальном браузере.

Уточнение клавиатурного контракта: Escape при раскрытом выборе родителя сначала закрывает список, сохраняя форму и черновик; следующий Escape закрывает форму. Выбор поддерживает стрелки, Home/End и Enter/Space, после выбора фокус остаётся на кнопке селекта. Несколько открытых ошибок имеют независимые доступные названия.
