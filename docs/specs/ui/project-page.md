# Карточка проекта — /projects/:projectId

Отображение: название, описание, документация, статус, счётчик Opened-фич; таблица фич с названием, описанием, статусом и действиями. Фильтр фич по статусу, изначально все; строка ведёт в карточку фичи.

Перо проекта включает inline-редактирование названия, описания и документации. «Сохранить» сохраняет через UpdateProjectCard. Повторное перо с изменениями открывает существующий диалог «Сохранить изменения?»; «Да» сохраняет, «Нет» отбрасывает, Escape возвращает к редактору. Без изменений редактор закрывается сразу. Во время сохранения повторная отправка запрещена.

«Добавить фичу» открывает модалку с названием и описанием и фиксированным текущим проектом; для Closed действие недоступно по P-04. Изменение фичи открывает форму с текущими значениями; остальные действия следуют F-02/F-03. После изменений фич обновляются и таблица, и счётчик проекта.

Контракты: [проекты](../application/projects.md), [фичи](../application/features.md), [диалоги](dialogs.md). При ошибке чтения/записи показана ошибка; ошибочное сохранение не уничтожает черновик.

Приёмка: новая фича привязана именно к текущему проекту; изменение её статуса обновляет openedFeatureCount; документация сохраняется после повторного открытия страницы.

Переход истории браузера на другую карточку меняет контекст целиком: прежний редактор/модалка и данные не переносятся на новую сущность; переход сам по себе ничего не сохраняет.
