# Карточка фичи — /features/:featureId

Отображение: название, описание, статус, название проекта, количество задач строго в Open; таблица только задач этой фичи. Фильтр статуса задач изначально показывает все; строки/ссылки ведут в карточки задач.

Перо фичи открывает редактор названия и описания. Смена статуса и удаление следуют [Feature](../domain/feature.md); после успешного удаления переход к списку фич. Вопрос об отдельном редактировании родительского проекта здесь остаётся [Q-01](../questions.md).

«Добавить задачу» открывает модалку названия/описания, родитель фиксирован текущей фичей. Редактирование задачи открывает заполненную форму, действия статуса/удаления следуют T-02/T-03. После изменения задачи обновляются таблица и счётчик независимо от фильтра; новая Open-задача может быть скрыта выбранным фильтром, но видна при «Все».

Контракты: [фичи](../application/features.md), [задачи](../application/tasks.md), [диалоги](dialogs.md). Отсутствующая фича и ошибка загрузки явно отображаются, бесконечная надпись «Загрузка» недопустима.

Переход истории браузера на другую карточку меняет контекст целиком: прежний редактор/модалка и данные не переносятся на новую сущность; переход сам по себе ничего не сохраняет.
