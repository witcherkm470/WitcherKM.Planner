# Карточка задачи — /tasks/:taskId

Отображение: название, описание, статус, фича и проект. Ссылки на фичу/проект открывают соответствующие карточки.

В шапке статус и действия в порядке: смена статуса, перо, череп. Набор следует T-02/T-03, у Done действия скрыты. Перо открывает модалку с текущими названием/описанием; сохранение обновляет карточку. Удаление после успеха возвращает к /tasks. Смена статуса обновляет карточку.

Контракты: [задачи](../application/tasks.md), [диалоги](dialogs.md). Загрузка, ошибка и отсутствие данных различимы. При ошибке изменения карточка и черновик остаются доступными.

Приёмка: видны статус и оба родителя, переходы работают; редактирование открывает форму; терминальное состояние не предлагает запрещённых действий.
