# Initial spec: задачи

## Контекст

Эта спецификация определяет требования для страницы задач.

## Требования

- Задача имеет название, описание. Каждая задача относится к определенной фиче. У задачи есть 3 статуса. Open -> InProgress -> Done.
- Новая задача создаётся со статусом Open.
- Пользователь может получить список задач. Список задач показывается пользователю в виде таблицы со столбцами название, статус и кнопки действий.
- Должна быть возможность редактировать и удалять задачи, запрещено редактировать и удалять задачи со статусом Done.
- Должна быть возможность поменять статус у задачи. Open -> InProgress -> Done. Задачу можно вернуть из статуса InProgress в статус Open. Статус у задачи со статусом Done невозможно изменить
- Каждая строка должна быть кликабельной и вести на карточку задачи. 

## Acceptance Criteria

- Создание задачи с пустым или состоящим только из пробелов названием завершается ошибкой доменной проверки.
- Созданная задача доступна в списке.
- Изменения задачи отражаются в возвращаемой модели идеи.
- Удаление и изменение идеи со статусом Done запрещено.
