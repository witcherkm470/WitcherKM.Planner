# Initial spec: задача

## Контекст

Эта спецификация определяет требования для карточки задачи.

## Требования

- Карточка задачи представляет собой подробную информацию о задаче. Карточка задачи содержит информаци о названии, описании, статусе, фиче к которой принадлежит и проекту. Связь Проект -> фича -> задача
- Пользователь может перейти к карточке фичи по клику на фичу и к карточке проекта при клике на проект.
- Страница содержит кнопки редактирования, удаления и изменения статуса задачи.

## Acceptance Criteria

- У задачи не может отсутствовать фича или проект.
- Изменения задачи отражаются в возвращаемой модели идеи.
- Удаление и изменение идеи со статусом Done запрещено.
