# Initial spec: переход на карточку фичи из карточки проекта

## Контекст

Эта спецификация определяет требования для списка задач в карточке фичи.

## Требования

- Каждая фича из списка кликабельна и ведет на страницу карточки фичи.
- У фичи возможно изменить статус.
- Фильтр по статусу фичей

## Acceptance Criteria

- Список фич отображается корректно
