## Исправления этого прохода

| Подтверждённый дефект | Исправление и проверка |
| --- | --- |
| Старый ответ/ошибка заменяет данные нового фильтра; старый запрос преждевременно завершает загрузку | useApiRequest принимает результат только актуального вызова. Две новые регрессии сначала падали. |
| Отложенная запись обновляет прежний фильтр; после ухода со страницы запускается её callback | Актуальный callback и отмена применения UI-результатов после unmount. Две регрессии red → green. Серверная запись не отменяется. |
| Escape в списке выбора родителя закрывает форму, стрелки не работают, фокус теряется | FilterSelect: стрелки/Home/End, Enter/Space, закрытие только списка, возврат фокуса. Две регрессии red → green, браузерный сценарий. |
| Несколько ErrorModal имеют одинаковый title id | Независимые useId; тест доступных названий red → green. |
| Переход к другой карточке оставляет старую модалку или режим редактирования | Состояние страницы ограничено идентификатором сущности. Три карточки проверены компонентно (red → green), задачи — прямым history-переходом в Edge. |
| После ошибки сохранения браузер не возвращает фокус в форму: submit был disabled и фокус ушёл в body | ModalFrame помнит последний фокус родительского диалога. Новый browser test обнаружил дефект и прошёл после исправления. |

Новых видов модалок в этом проходе не потребовалось: в исходном `112238e` уже были create/edit проекта, фичи, задачи, идеи и подтверждение несохранённых изменений проекта. Проверены их точки открытия; исправлены составной выбор родителя, вложенные ошибки, фокус и жизненный цикл. Inline-редактор проекта сохранён по существующему контракту. Дополнительных подтверждений удаления не вводилось.
