# Активные изменения

Здесь размещаются незавершённые change-документы. Формат: источник и цель; изменяемые требования со ссылками; критерии приёмки; реализация и тесты; открытые вопросы; статус. Завершённые изменения находятся в ../archive. Обсуждение открытых продуктовых вопросов без утверждённого изменения ведётся в ../../questions.md.
