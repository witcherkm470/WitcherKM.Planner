# Initial spec: фичи

## Контекст

Эта спецификация фиксирует только уверенно восстанавливаемое существующее поведение фич. Она не определяет новые требования.

## Требования

- Фича имеет непустое название, необязательное описание и относится к существующему проекту.
- Пользователь может получить общий список фич и список фич конкретного проекта.
- Пользователь может создать фичу и изменить её название и описание.
- Созданная фича получает состояние `Opened`.

## Acceptance Criteria

- Создание фичи с пустым или состоящим только из пробелов названием завершается ошибкой доменной проверки.
- Создание фичи для отсутствующего проекта не выполняется.
- После создания фича присутствует в общем списке и в списке фич соответствующего проекта.
- Изменения названия и описания отражаются в возвращаемой модели фичи.
