# Initial spec: страница карточки фичи

## Контекст

Эта спецификация определяет требования для карточки фичи.

## Требования

- Показывается список задач, относящихся к этой фиче.
- Фильтр задач по статусу. Изначально показываются все задачи.
- Каждая задача в списке кликабельна и ведет на страницу задачи.
- Есть кнопка добавления новой задачи сразу в эту фичу. По нажатию открывается модальное окно для добавления задачи. 
- Должна быть возможность поменять статус у задачи.
- Кнопки редактирования проекта.
- Количество открытых задач у этой фичи
- В карточке показывается Навзание, Описание, Статус

## Acceptance Criteria

- Список задач отображается корректно
- Новая задача автоматически попадает в список задач в карточке фичи
