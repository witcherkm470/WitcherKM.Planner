# Сценарии задач

Правила: [TaskItem](../domain/task.md). Адаптер: TasksController; маршруты /api/tasks и /api/tasks/{id}.

| Сценарий | Вход и оркестрация | Результат |
| --- | --- | --- |
| ListTasks | необязательные featureId и taskStatus; прочитать связанные объекты и применить фильтры | Список моделей задач |
| GetTask | taskId; загрузить задачу с Feature.Project | Полная модель |
| AddTask | name, description, featureId; проверить существование фичи, создать, сохранить, прочитать полную модель | Созданная модель |
| UpdateTask | taskId, name, description; загрузить, вызвать Update, сохранить | Обновлённая модель |
| ChangeTaskStatus | taskId, taskStatus; загрузить, вызвать метод перехода, сохранить | Обновлённая модель |
| RemoveTask | taskId; загрузить, вызвать доменную проверку удаления, удалить и сохранить | Без тела |

Модель содержит id, name, description, taskStatus, featureId, featureName, projectId, projectName. Во всех успешных чтениях и ответах изменения цепочка родителей заполнена; родитель не определяется догадкой клиента.

Отсутствующая задача или родитель → EntityNotFoundException; неподдерживаемый enum → ошибка без записи. Приёмка: данные записываются между независимыми запросами; фильтры возвращают только нужную фичу/статус; ошибки не меняют сохранённое состояние.
